## 👑 Team Leader & My Contribution

본 프로젝트에서 **팀장으로 참여하여 프로젝트 전체 시스템 구성과 코드 통합을 담당했으며**,  
멀티플레이 시스템과 게임의 전체적인 사용자 인터페이스를 중심으로 구현했습니다.

| 담당 영역 | 주요 구현 내용 |
|---|---|
| 👑 **Team Leader** | 프로젝트 개발 방향 조율 및 팀원별 구현 기능의 최종 코드 통합 |
| 🌐 **TCP/IP 네트워크 연동** | 방 생성·참가, 플레이어 접속, 게임 데이터 송수신 및 멀티플레이 연동 |
| 💬 **실시간 채팅** | 닉네임 기반 채팅 입력, TCP/IP 메시지 송수신 및 게임 화면 출력 |

| 🌙 **야간 시야 제한** | 밤 스테이지에서 플레이어 주변만 보이도록 시야 제한 렌더링 구현 |
| 🎨 **Game UI / Design** | 메인 메뉴, 로비, HUD, 채팅창, 버튼 등 게임 UI 및 전체 디자인 구성 |
