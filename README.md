# 🏴‍☠️ Pirate Defense

### C++ · SFML · TCP/IP 기반 멀티플레이 협동 디펜스 게임

여러 플레이어가 하나의 해적선을 함께 방어하며 적과 보스를 상대하는  
**TCP/IP 기반 멀티플레이 협동 디펜스 게임**입니다.

플레이어는 방을 생성하거나 **방 코드로 참가**할 수 있으며,  
실시간으로 게임 상태를 공유하고 채팅하며 협력하여 스테이지를 진행합니다.

---

## 💡 Project Background

본 프로젝트는 **C++ 팀 프로젝트**로 진행한 멀티플레이 협동 디펜스 게임입니다.

단순한 싱글 게임 구현에서 끝나지 않고,

> **방 생성 → 멀티플레이 참가 → 실시간 동기화 → 협동 전투 → 채팅**

으로 이어지는 네트워크 게임 구조를 구현하는 것을 목표로 개발했습니다.

게임 그래픽과 UI는 **SFML**을 기반으로 구성했으며,  
멀티플레이 기능은 **TCP/IP 네트워크 통신**을 활용하여 구현했습니다.

플레이어는 동일한 방에 접속해 하나의 선박을 방어하며  
적과 보스를 상대하고, 낚시 · 아이템 · 상점 · 업그레이드 등의 시스템을 활용해  
스테이지를 함께 진행할 수 있습니다.

## 🎯 Key Point

본 프로젝트의 핵심은 단순히 게임 콘텐츠를 구현하는 것뿐만 아니라,

> **여러 플레이어가 하나의 게임 상태를 공유하며 협력할 수 있는 구조**

를 만드는 것이었습니다.

특히 **TCP/IP 기반 네트워크 통신**을 통해  
플레이어 입력과 게임 데이터를 실시간으로 동기화하고,

**방 코드 기반 멀티플레이 · 닉네임 · 실시간 채팅 · SFML UI 시스템**을 결합하여  
멀티플레이 게임의 전체적인 사용자 흐름을 구현했습니다.

또한 낮 → 저녁 → 밤으로 변화하는 스테이지 환경과  
야간 시야 제한, 적 및 보스 패턴, 상점과 아이템 시스템 등을 결합하여  
단순한 네트워크 통신 예제가 아닌 하나의 협동 디펜스 게임으로 구현했습니다.

## 💻 My Main Implementation

김초아 담당 기능은 소스코드 내부에서도  
`[김초아 담당]` 주석을 통해 확인할 수 있도록 정리했습니다.

```text
TCP/IP Networking
      ↓
Room / Player Connection
      ↓
Real-Time Synchronization
      ↓
Real-Time Chat
      ↓
Main SFML System
      ↓
Game System Integration
      ↓
UI / HUD / Night Vision
```

주요 담당 코드는 다음 파일에서 확인할 수 있습니다.

| File | 담당 기능 |
|---|---|
| `NetworkManager.h` | 네트워크 시스템 구조 및 데이터 정의 |
| `NetworkManager.cpp` | TCP/IP 연결, 데이터 송수신, 실시간 채팅 |
| `main.cpp` | 메인 SFML 시스템, 로비, 화면 전환, 채팅 UI |
| `MultiGame.cpp` | 네트워크 시스템과 실제 멀티플레이 게임 루프 통합 |
| `Render.hpp` | 게임 UI / HUD 및 야간 시야 제한 렌더링 |
